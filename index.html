GitHub pour le partage
Token et dépôt pour le partage
📘 Comment configurer le partage GitHub :
1. Créez un token GitHub classique : allez dans Settings → Developer settings → Personal access tokens → Tokens (classic).
2. Cochez la permission repo (plein accès aux dépôts privés).
3. Créez un dépôt vide sur GitHub (ex: cashflow-shares).
4. Copiez le token et le nom du dépôt (utilisateur/repo) dans les champs ci-dessus.
5. Cliquez sur Enregistrer puis allez dans l'onglet Partage.
💡 Le token est stocké localement dans votre navigateur.
